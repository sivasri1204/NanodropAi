# Companion App / Speech Output

This folder is reserved for a future companion app or speech-output integration.

Possible responsibilities:
- Receive classified gesture labels from the ESP32 over BLE/Wi-Fi/serial, depending on the design.
- Map a verified label to a short text phrase.
- Use platform text-to-speech.
- Let users configure alert volume, vibration patterns, and supported phrases.
- Provide clear status and connection-loss indicators.

Choose one communication method for the first prototype and document its pairing and privacy behaviour.
